## 修复

- 按原生 step_index 合并文字、工具和中间错误；连续工具仍使用虚拟列表，文字保留原有增量渲染。迟到工具输出只更新原位置。结果只含正文时分配最后一步。旧历史没有正文索引时放在已知工具之后，不伪造原始时间戳。
- 接受真实 CLI 1.2.16 的 error_message。通过本地故障端点捕获确认：中间事件不带错误正文；界面因此只说“CLI 报告错误，等待恢复或最终结果”，不推断具体网络原因。最终错误保留原文。
- 只有明确错误事件启动恢复监测：连续三个不同错误步骤无有效进展，或首次错误后 120 秒没有新进展，停止本轮扩展创建的进程组。新文字、新工具或工具状态/输出变化会复位。重复同一步错误不重复计数，普通慢任务没有超时。CLI 自身仍负责恢复；扩展不额外重发模型请求或工具操作。停止不能回滚已发生的文件修改。
- 工具默认显示紧凑动作/目标摘要，完整参数和原文按需展开/分页。明确非零退出记录为失败；Traceback/sudo 密码标记显示“输出包含异常”，不把任意日志词语猜成失败。后台执行和结束时未确认结果分别标示；不再一律显示绿色成功勾。
- Mermaid/其他图表和纯文本围栏没有文件操作栏。普通代码只提供复制；明确包含 file= 或 path= 目标的代码才有差异预览/应用，仍要求后台来源、目标文档和版本校验。原始围栏索引保持不变。
- 空回复的失败/取消轮次显示本地状态说明。失败/停止后提供“准备续接”，只填写可审阅的草稿，不自动发送；提示先检查已有文件，避免重复工作。
- 每条消息时长改为本轮墙钟时长，避免将原生会话累计时长误显示为本轮耗时。原生累计 Token 统计逻辑未更改。
