# 2.1.1 Plan 读取拒绝修复

用户会话在读取 `/home/ubuntu/project/blender2` 的父目录时收到 CLI `denied_actions: [{action: read_file, display_name: ListDir}]`。这是 headless CLI 自动拒绝；原界面“需要确认”误导为待审批状态。

- 会话、工具卡和错误提示明确显示 CLI 自动拒绝，没有待审批请求。
- Plan 提示约束必要读取到工作区/附加目录，缺少信息时说明假设并输出方案。
- Plan 仅有 read_file 拒绝且没有方案正文时，在同一个只读进程、同一个界面轮次内续写一次，请求不再调用工具并据已有信息输出方案。保留拒绝记录和工具卡，不增加可见用户消息。
- 第二次拒绝不再自动续写；停止、代次检查、输入恢复仍有效。未扩大工具白名单、未启用 Danger、未修改用户设置。
- 已有方案正文的成功 Plan 不因只读拒绝被标记为等待权限，可以明确批准实施。

39 项测试通过，新增拒绝后续写、重复拒绝有界退出、真实 React → Provider → Coordinator → 模拟 CLI 的可见方案/提示回归。真实 CLI 与安装窗口验证记录见 diagnostics/2.1.1-*.json。

性能：正常轮次没有新增轮询；仅无正文读取拒绝时增加最多一次模型续写，因此该异常路径会增加模型等待时间。只读 Agent 限制继续保留；不承诺提示词能强制模型完全不再读取。
