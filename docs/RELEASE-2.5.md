## 协议与平台边界

已验证 CLI 1.2.14、1.2.16。当前主界面无法可靠逐工具挂起审批；精确子代理生命周期、深层关系和独立Token缺可靠协议，显示未知或提供原生入口。Schema实验，sandbox启动不等于OS隔离。`/diff`、`/edited`为Git工作树/HEAD范围，不能归因到某一轮。

WSL/POSIX为验收目标；Windows工具进程树与旧版VS Code运行时尚未取得同等证明。窗口重载会终止该扩展宿主持有的执行器；外部终端跨宿主重载的锁接管未验证，不自动释放活跃锁。

## 记录保留与离线归档

会话目录的 `session.json`、messages 与 tools 文件是恢复数据；`events.ndjson`只追加消息ID/文件/状态等索引。它不会替代元数据提交，也不是崩溃耐久性日志。

当前不自动删除用户历史或修剪 events；磁盘总历史量由用户保留时长决定，内存/写入预算不是磁盘容量上限。需要压缩时，先在独立备份目录复制已停止、无执行者的会话，核对文件哈希，再压缩**备份副本**；保留原 messages/tools/metadata、迁移来源和原生日志。在线目录、活跃锁和未确认归属的旧锁不做自动归档或删除。恢复前核对CLI目录/配置和执行者，不能把备份中的active.lock作为新实例的执行权。
